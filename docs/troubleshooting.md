# Troubleshooting

- Plugin not loaded: refresh Codex and start a new task after install.
- Stale project path: re-open/register the exact checkout, refresh projects, and rerun Doctor.
- Dispatch rejected: confirm the current Plan revision, target identity, ready state, and ContextPack budget.
- Schema mismatch: use the supported migration path or restore a snapshot.
- Worker result rejected: verify Plan ID, revision, unit, status, summary, and validation array.
- Memory conflict: invalidate or explicitly supersede the old item.
